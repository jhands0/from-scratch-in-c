# Doppler

This program contains an object the produces waves that propergate from itself.
The object can be moved to visualise the doppler effect.

## Getting Started

### Prerequisites

#### Debian/Ubuntu

#### Fedora

#### From Source

### Installation

1. Clone the repo

```sh
git clone -b doppler https://github.com/jhands0/from-scratch-in-c.git
```

2. Build the program

```sh
make release
```

## Usage

```sh
./out
```
